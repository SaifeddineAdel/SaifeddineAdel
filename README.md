## 🚀 Featured Projects

### 🚇 01. Smart Metro Trip Planner

**A Scalable Microservices-Based Metro Route Planning System**

A backend system designed to help users plan metro journeys by calculating routes between stations across multiple metro lines, providing an efficient and structured approach to metro network navigation.

**Architecture & Engineering Highlights**

- Designed a microservices architecture separating Metro Network management from Trip Planning responsibilities.
- Implemented an API Gateway using YARP to provide a unified entry point for backend services.
- Built a graph-based representation of the metro network to support route calculation and traversal.
- Implemented pathfinding logic to determine routes between stations.
- Designed a Redis-based snapshot publishing and synchronization mechanism to distribute metro network updates between services.
- Built an in-memory network graph to reduce repeated database and inter-service requests during trip planning.
- Containerized the services and their dependencies using Docker Compose.
- Configured automated build and test workflows using GitHub Actions.

**Tech Stack**

`C#` `ASP.NET Core` `SQL Server` `Entity Framework Core` `Redis` `YARP` `Docker` `GitHub Actions` `Graph Algorithms`

### 🔎 02. LostAndFound

**A Backend Management System for Lost and Found Items**

A backend application designed for closed environments to manage lost and found item reports, helping users submit reports while enabling staff to review, approve, and manage reported items through a structured administrative workflow.

**Core Functionality & Engineering Highlights**

- Developed RESTful APIs for creating and managing lost and found reports.
- Implemented an administrative review workflow with report submission, approval, and rejection.
- Designed a hierarchical category and subcategory structure for organizing reported items.
- Implemented authentication and role-based authorization using ASP.NET Core Identity and JSON Web Tokens.
- Applied domain-specific validation rules to ensure report data integrity.
- Integrated RabbitMQ for publishing domain-related events and enabling asynchronous communication.
- Implemented Entity Framework Core configurations, relationships, and database constraints.
- Used FluentValidation to centralize request validation.

**Tech Stack**

`C#` `ASP.NET Core` `SQL Server` `Entity Framework Core` `ASP.NET Core Identity` `RabbitMQ` `FluentValidation`
